========================================
TM-1637 SEGMENT BENCH -- QUICK REFERENCE
========================================

TRANSPORT
  Restart (⟲)      Jump to the first enabled step, reset its timer
  Play / Pause     Toggle autoplay
  Step ▸           Advance one step by hand (works while paused too)
  Brightness 0-7   Preview glow only -- not saved or exported

ADDING STEPS
  + Text step      Up to 4 chars, from the alphabet reference
  + Number step    Any integer, last 4 digits shown, right-aligned
  + Blank / pause  Empty text step, usually on the SHORT tier
  All three insert right after the CURRENT step, not at the end
  of the list -- lands where you're actually working.

EACH STEP ROW
  Checkbox   Unchecked = skipped in playback, but stays in the list
             (and in anything you save or export)
  ↑ / ↓ / ✕  Reorder / delete

TIMING TIERS
  LONG    50-1200ms   main content -- a word/number meant to be read
  MEDIUM  50-1200ms   secondary/repeated words, status labels
  SHORT   20-1200ms   blanks, quick pulses between words
  custom              per-step override, own ms value

  Display polls every ~150ms (matches real firmware), so "actual"
  on-screen time rounds UP to the next poll past your target --
  e.g. 460ms target -> ~600ms actual. Real hardware adds its own
  jitter on top of this.

SAVE vs LOAD vs EXPORT
  💾 Save data file   Writes .json: tiers + brightness + steps +
                      firmware target (see below). Nothing autosaves
                      -- save before navigating away. Chrome/Edge:
                      opens your OS's native save dialog; overwrites
                      the same file quietly after that, like Ctrl+S.
                      "Save As..." picks a different file/folder.
                      Firefox/Safari: falls back to a plain download.
  📂 Load data file   Reopens a saved sequence, through TODAY's
                      display logic (fixes made to the page apply
                      retroactively to old saves). Reconnects Save
                      to the exact file you opened.
  ⤓ Export config     Firmware-facing JSON: tiers + steps (incl.
                      disabled ones) + firmware target, no
                      brightness/position. For handing off, not
                      for continuing to edit.

  Folder memory: once you've saved/loaded anywhere, every picker
  after that (Save, Save As, Load) defaults into that same folder
  automatically -- remembered even across restarting the browser.
  The very first save on a fresh browser profile can't know where
  this page itself lives (browsers don't expose that), so it opens
  wherever your browser defaults to; pick your folder that first
  time and it'll stick from then on.

FIRMWARE TARGET
  Dropdown above the step list: tags a sequence with which display
  state/cycle in YOUR firmware it's meant to drive, plus an
  optional Note field for extra context. Saved/exported with the
  file. Ships with placeholder entries -- edit the FIRMWARE_TARGETS
  array near the top of the <script> block to match your own
  project's state names. An unrecognized saved target (old file,
  renamed entry) falls back to "Other" with the original value
  folded into the note, so nothing's silently lost.

ALPHABET GOTCHAS
  R N D T B Q Y   Only ONE physical shape exists per letter -- typing
                  the uppercase spelling (e.g. "END", "OVR") still
                  lights the "lowercase-looking" shape. Correct, not
                  a bug: "END" reads as "End" on screen.
  I vs i          Deliberately drawn as two different glyphs here
                  (2-segment bar vs. single stroke), even though real
                  firmware usually sends the same segment for both.
  Legend dots:    accent = common convention (most 7-seg fonts)
                  faint  = playground / approximate, less standard

FILENAME CONVENTION (Save data file)
  <word-code><speed>-<word-code><speed>-...
  speed codes: L / M / S, or C<ms> for custom
  Spellings that render identically share one code -- "Ovr" and
  "OVR" look the same on the display (R/N/D/T/B/Q/Y only have one
  physical shape), so they're grouped as one word. Spellings that
  genuinely render differently ("Hi" vs "HI" -- I/i are distinct
  glyphs here) still get separate codes.
  Rename the download freely -- it doesn't affect the file contents.

GOTCHAS
  - Nothing autosaves, including across reloads.
  - Text >4 chars truncates; unsupported chars are flagged on the row.
  - Save data file != Export config -- save/load is for continuing
    to work here; export is for handing off to firmware.
