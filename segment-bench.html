Segment Bench

A browser-based simulator for a TM1637-style 4-digit 7-segment display — design and preview text/number message sequences with LONG / MEDIUM / SHORT display tiers and ~150ms refresh quantization, without flashing any hardware.

as .json

Nothing here is saved automatically -- edits are exploratory until you click "Save data file". That downloads a plain JSON file -- tiers, brightness, and the step list, nothing else -- under the name shown; with your browser set to ask where to save, the dialog will warn you if that name already exists so you can increment it. Reopen a saved sequence later with "Load data file", right here on THIS page. A data file never carries its own copy of this tool's display logic, so it can't go stale the way a saved copy of the whole page could: if this page ever gets a fix (a new supported character, a display correction), every data file you load through it benefits immediately -- nothing about a sequence you saved months ago needs re-saving. Open two different data files, one after another, to compare sequences.

Timing tiers

The display-refresh loop only polls every ~150ms — same as the real firmware — so a duration doesn't actually end until the first poll that lands past it. "Actual" above is that quantized value, not the raw number you typed. Real hardware has timing jitter this estimate doesn't model.
