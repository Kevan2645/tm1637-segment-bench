A browser-based simulator for a TM1637-style 4-digit 7-segment display — design and preview text/number message sequences with LONG / MEDIUM / SHORT display tiers and ~150ms refresh quantization, without flashing any hardware.

Timing tiers

The display-refresh loop only polls every ~150ms — same as the real firmware — so a duration doesn't actually end until the first poll that lands past it. "Actual" above is that quantized value, not the raw number you typed. Real hardware has timing jitter this estimate doesn't model.
